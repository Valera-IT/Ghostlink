# 0005. Koin вместо Hilt

**Статус:** принято, действует с пункта 3.7

**Контекст.** Hilt работает только на Android. Для KMP нужен DI, который работает в `commonMain`.

**Решение.** Koin. Каждый модуль отдаёт `val xxxModule = module { … }`, а app-модуль собирает их и выбирает бэкенд: demo, emulator или Firebase.

**Последствия.** Граф проверяется в рантайме, а не при компиляции. Компенсируем тестом `KoinModulesTest` (`verify()`) в CI.
