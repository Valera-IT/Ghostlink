# 0001. Только Firebase Spark, без своего сервера

**Статус:** принято

**Контекст.** Проект бесплатный и портфельный. Blaze требует карту и включает Cloud Functions, но за ошибку в коде можно получить счёт.

**Решение.** Используем только Spark: Auth и Firestore. Всё, что обычно делает сервер, делают клиент и правила: привязку устройств, отзыв сессий, проверку прав. Push (этап 6) уходит через Cloudflare Worker на бесплатном тарифе.

**Последствия.**
- Нет TTL и бэкапов, поэтому клиент сам удаляет свои заявки.
- Нельзя принудительно отключить одно устройство. Отзыв либо мягкий (удаление из реестра), либо полный (смена секрета).
- Правила — единственная защита данных, поэтому их покрываем тестами в CI.
