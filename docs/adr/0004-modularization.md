# 0004. Модули по фичам и слоям

**Статус:** принято

**Контекст.** Один модуль `app` удобен до первой платформы. Дальше общий код смешивается с платформенным, сборка не кешируется, а границы слоёв держатся только на дисциплине.

**Решение.** Модули `core:*` (model, domain, data, firebase, crypto, platform, designsystem, ui, testing, demo), `feature:*` (по одному на пользовательский сценарий) и `apps:*`. Общие настройки Gradle лежат в convention-плагинах `build-logic`. Граф зависимостей проверяется в CI.

**Последствия.** Модулей больше, и для новой фичи нужен шаблон. Взамен компилятор не даёт фиче обратиться к Firebase, сборки идут параллельно, а модули тестируются отдельно.
