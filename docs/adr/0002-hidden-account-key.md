# 0002. Скрытый email/password-аккаунт из ключа на устройстве

**Статус:** принято

**Контекст.** Идея продукта — без телефона и почты. Анонимный аккаунт Firebase нельзя открыть на втором устройстве.

**Решение.** Аккаунт — это 25 случайных байт. Из 8 байт получается служебная почта `…@ghostlink.invalid`, из 17 — пароль. Новое устройство получает ключ по QR через ECDH P-256 → HKDF-SHA256 → AES-256-GCM. Ключ восстановления — те же 25 байт в base32.

**Последствия.** Если потерять все устройства и ключ восстановления, аккаунт пропадает. «Выйти на всех» меняет пароль, и старый ключ восстановления перестаёт работать. Протокол привязки описан в README.
